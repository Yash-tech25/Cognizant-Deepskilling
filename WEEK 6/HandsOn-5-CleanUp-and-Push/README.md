# Git Hands-on 5 - Clean Up and Push to Remote

## Objective
Learn how to clean up the repository and push changes to a remote Git repository.

## Commands Used

git status
git branch
git pull origin master
git push origin master

## Note

This hands-on was practiced using a local Git repository (GitDemo). Since the repository had no remote (`origin`) configured, the `git pull` and `git push` commands could not be demonstrated. All completed hands-on deliverables were maintained and pushed through the Cognizant-Deepskilling GitHub repository.
